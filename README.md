# Interactive Java Calculator with Memory (MS)

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)
![Status](https://img.shields.io/badge/status-completed-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

A desktop calculator developed in Java featuring graphical input dialogs and a memory accumulator. The application handles fundamental arithmetic operations (addition, subtraction, multiplication, and division) within a continuous execution loop, applying core Object-Oriented Programming (OOP) concepts.

## 📌 Overview & Features

* **Dialog-based GUI:** Utilizes standard Java Swing dialogs (JOptionPane) for interactive numeric inputs and result displays.
* **Object-Oriented Architecture:** Computation logic is separated into an independent class (Calculadora) with private state encapsulation, getters, setters, and extensible structure (CalculadoraCientifica).
* **Memory Management (MS):** Stores an accumulated value across computations, supporting addition (M+) and subtraction (M-) into memory.
* **Continuous Flow:** Runs in an interactive loop allowing multiple successive calculations until the user chooses to exit.

## 🎓 Learning Context

Developed to practice and consolidate core Java fundamentals, object encapsulation, and GUI message dialogs. This implementation represents the evolution of an earlier Python CLI calculator project, transitioning procedural logic into an object-oriented structure.
